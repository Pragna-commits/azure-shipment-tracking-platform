# Azure Shipment & Tank Tracking Platform

## Project Overview

A cloud-based shipment and ISO tank tracking platform built on Microsoft Azure.

This project demonstrates practical cloud architecture concepts including application deployment, databases, storage, security, monitoring, scalability, Infrastructure as Code and CI/CD.

## Business Problem

The platform is designed for a logistics and shipping organization to track:

- Shipment / Job Number
- Customer
- Tank Number
- Vessel
- Origin
- Destination
- ETD
- ETA
- Shipment Status
- Tank Status

## Cloud Architecture

The solution will progressively implement:

- Azure App Service
- Azure SQL Database
- Azure Blob Storage
- Microsoft Entra ID
- Azure Key Vault
- Azure Virtual Network
- Azure Monitor
- Application Insights
- Azure Service Bus
- Terraform
- GitHub Actions
